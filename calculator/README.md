## ✨ Tính năng

- Hỗ trợ tính toán: cộng (`+`), trừ (`-`), nhân (`*`), chia (`/`)
- Hỗ trợ biểu thức phức tạp (nested expressions) ví dụ: `3 * 4 + 5`
- Xử lý lỗi cho biểu thức rỗng hoặc chứa chỉ khoảng trắng
- Xử lý lỗi cho toán tử không hợp lệ
- Xử lý lỗi khi số lượng toán hạng không đủ

## 🚀 Cài đặt & Sử dụng

```bash
# Clone dự án
git clone <repository-url>

# Chạy ứng dụng
python main.py "3 + 5"

# Chạy bộ test
python tests.py
```

## 📝 Ví dụ

```bash
python main.py "3 + 5"
# Output: {"expression": "3 + 5", "result": 8}
```
